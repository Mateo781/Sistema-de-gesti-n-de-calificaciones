Sistema de Gestión de Calificaciones
7° Año – Programación
Objetivo General
Desarrollar una aplicación modular para la gestión de calificaciones académicas, alineada con el nuevo régimen académico, que contemple instancias de evaluación, períodos de intensificación y recursada de materias.El sistema deberá funcionar sobre el servidor institucional (GEdeCon) e incluir una PWA instalable en dispositivos móviles.
 Usuarios del Sistema
Docente
Registra calificaciones.
Gestiona evaluaciones por materia.
Define instancias de intensificación o recursada.
Administrador
Gestiona usuarios.
Configura materias, cursos y ciclos lectivos.
Supervisa el sistema.
Alumno
Consulta sus calificaciones.
Visualiza su situación académica.
Accede a instancias de intensificación o recursada.
Padres / Tutores
Visualizan el rendimiento académico del alumno.
Consultan calificaciones e instancias pendientes.

Investigación previa (REQUERIDO)
Antes del desarrollo, cada grupo deberá:
Investigar cómo funciona el nuevo régimen académico vigente.
Analizar cómo se evalúan las trayectorias escolares.
Tener en cuenta los RITE (Regímenes Institucionales de Trayectoria Educativa).
Definir, en base a esa investigación, cómo se modelará el sistema de calificaciones.

CONSIDERACIONES
El sistema debe representar un modelo realista del sistema educativo actual.
La investigación es parte fundamental del proyecto.
No se evaluará solo el código, sino también la correcta interpretación del régimen académico.
Trabajo grupal.
DESAFÍO
El objetivo es que los estudiantes logren:
Interpretar normativa educativa real
Modelar reglas académicas complejas
Integrar lógica institucional en un sistema informático
Resultado esperado: Un sistema modular, funcional y fundamentado en el régimen académico vigente, capaz de gestionar calificaciones y trayectorias escolares de manera completa y coherente.
